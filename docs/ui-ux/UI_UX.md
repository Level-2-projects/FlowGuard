# FlowGuard - UI/UX Design

## 1. Design Overview
FlowGuard uses a modern SaaS dashboard interface designed to make project scheduling and risk analysis easy to understand.

## 2. Visual Identity

- Primary Background: Dark Navy
- Primary Accent: Electric Blue
- Secondary Background: White
- Text: Dark Gray and White
- Style: Modern, clean, minimal, and professional
- Layout: Desktop-first responsive interface

## 3. Main Screens

### Screen 1: Dashboard
Purpose: Give the Project Manager a quick overview of the project.

Main Elements:
- Sidebar navigation.
- Project title.
- Total tasks.
- Completed tasks.
- Pending tasks.
- Delayed tasks.
- Overall progress indicator.
- Upcoming deadlines.
- Critical tasks summary.

### Screen 2: Tasks Management
Purpose: Allow the Project Manager to organize and manage project tasks.

Main Elements:
- Tasks table.
- Task title.
- Assigned member.
- Duration.
- Start and end dates.
- Task status.
- Add Task button.
- Edit and Delete actions.
- Dependency information.

### Screen 3: Schedule Analysis
Purpose: Display scheduling calculations and identify critical tasks.

Main Elements:
- Project timeline.
- Task dependency visualization.
- Critical Path highlighted.
- ES, EF, LS, and LF values.
- Slack values.
- Project completion date.

### Screen 4: Delay Simulator
Purpose: Help the Project Manager understand the impact of a possible delay.

Main Elements:
- Task selection.
- Delay duration input.
- Simulate button.
- Original completion date.
- New estimated completion date.
- Delay impact summary.
- Baseline and scenario comparison.

## 4. Navigation Structure

- Dashboard
- Projects
- Tasks
- Schedule Analysis
- Delay Simulator
- Settings

## 5. UX Guidelines
- Keep navigation consistent across screens.
- Use clear labels and simple actions.
- Highlight critical tasks clearly.
- Display validation errors in understandable language.
- Confirm important destructive actions.
- Use consistent colors and spacing.
- Make important schedule information easy to find.
