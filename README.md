# FlowGuard

**Smart Project Planning and Delay Prevention System**

FlowGuard helps small project teams plan work, understand task dependencies, identify schedule-critical tasks, and simulate the impact of delays before they affect the whole project.

## Project documents
- [Project Requirements](REQUIREMENTS.md)
- [Concept and Tools](CONCEPT_AND_TOOLS.md)
- [Software Design Diagrams](docs/designs/DESIGN_DIAGRAMS.md)
- [UI/UX Wireframes and Figma link](docs/ui-ux/WIREFRAMES.md)

## Main features
1. Create and manage projects and tasks.
2. Assign tasks to team members and set estimated durations.
3. Define dependencies between tasks.
4. Calculate the Critical Path using the Critical Path Method (CPM).
5. Detect tasks that may delay the overall project.
6. Simulate a task delay and show its effect on the project finish date.
7. Provide a simple task-reassignment suggestion for demonstration purposes.

## Proposed MVP technology
- Backend: Python + Flask
- Database: SQLite
- Frontend: HTML, CSS, JavaScript
- Diagrams: Mermaid
- UI/UX: Figma
